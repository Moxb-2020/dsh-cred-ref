口令去哪了？

① 明文只存在 ~/.dsh/creds/servers.yaml（chmod 600）
② 宿主插件读文件 → SSHPASS 环境变量 → ssh，不进命令行
③ 对话、系统提示词、服务端日志里：只有别名和输出
④ 模型想 bash/read 凭据文件 → tools.guard() 硬拒绝

边界：防不住用户自己往对话里粘贴口令

模型得到的两个工具

cred_exec(alias, command)
按别名执行远程命令，只回传输出
cred_list()
列出别名+主机+用户（无口令）
tools.guard()
任何工具调用触碰凭据路径 → 拒绝
支持 ssh / telnet / PowerShell Remoting
